# 🎨 Design System Documentation\n\n## Overview\n\nThis document outlines the comprehensive design system for the Islamic Inheritance Calculator app. It follows Material Design 3 principles and professional standards for mobile applications.\n\n---\n\n## 📐 Design Tokens\n\n### Color System\n\n#### Primary Colors (Islamic Green)\n- **Primary**: `#4CAF50` - Main brand color\n- **Primary Light**: `#A5D6A7` - Lighter variant\n- **Primary Dark**: `#2E7D32` - Darker variant\n\n#### Secondary Colors (Professional Blue)\n- **Secondary**: `#2196F3` - Trust and stability\n- **Secondary Light**: `#90CAF9`\n- **Secondary Dark**: `#1565C0`\n\n#### Semantic Colors\n- **Success**: `#4CAF50` - Positive actions\n- **Error**: `#F44336` - Errors and warnings\n- **Warning**: `#FBC02D` - Important alerts\n- **Info**: `#03A9F4` - Informational messages\n\n### Spacing System\n\nBased on 4px base unit:\n\n```\nxs:    4px\nsm:    8px\nmd:   12px\nlg:   16px\nxl:   20px\nxxl:  24px\nxxxl: 32px\n```\n\n### Typography\n\n#### Display Sizes\n- **Display Large**: 57px, 400 weight\n- **Display Medium**: 45px, 400 weight\n- **Display Small**: 36px, 400 weight\n\n#### Heading Sizes\n- **Heading Large**: 32px, 700 weight\n- **Heading Medium**: 28px, 700 weight\n- **Heading Small**: 24px, 700 weight\n\n#### Body Sizes\n- **Body Large**: 16px, 400 weight\n- **Body Medium**: 14px, 400 weight\n- **Body Small**: 12px, 400 weight\n\n#### Label Sizes\n- **Label Large**: 14px, 600 weight\n- **Label Medium**: 12px, 600 weight\n- **Label Small**: 11px, 600 weight\n\n### Border Radius\n\n```\nxs:   4px\nsm:   8px\nmd:  12px\nlg:  16px\nxl:  20px\nfull: 9999px\n```\n\n### Shadows (Elevation)\n\n```\nNone:   No shadow\nSm:    1px elevation\nMd:    2px elevation\nLg:    4px elevation\nXl:    8px elevation\nXxl:  12px elevation\n```\n\n---\n\n## 🧩 Component Library\n\n### PrimaryButton\n\nMulti-purpose button component with variants and sizes.\n\n**Variants:**\n- `filled` - Solid background (default)\n- `outlined` - Border only\n- `elevated` - With shadow\n- `text` - Text only\n\n**Sizes:**\n- `sm` - 32px height\n- `md` - 40px height (default)\n- `lg` - 48px height\n\n**Props:**\n```typescript\ninterface PrimaryButtonProps {\n  title: string;\n  onPress: () => void;\n  variant?: 'filled' | 'outlined' | 'text' | 'elevated';\n  size?: 'sm' | 'md' | 'lg';\n  disabled?: boolean;\n  loading?: boolean;\n  icon?: string;\n  iconPosition?: 'left' | 'right';\n  fullWidth?: boolean;\n}\n```\n\n### ModernCard\n\nContainer component for grouping content.\n\n**Variants:**\n- `elevated` - With shadow\n- `filled` - Solid background\n- `outlined` - Border only\n\n**Props:**\n```typescript\ninterface ModernCardProps {\n  children: React.ReactNode;\n  variant?: 'elevated' | 'filled' | 'outlined';\n  padding?: number;\n  margin?: number;\n}\n```\n\n### ModernInput\n\nAdvanced text input with validation and icons.\n\n**Features:**\n- Label support\n- Error messages\n- Icon support (left and right)\n- Focus state styling\n- Multiline support\n\n**Props:**\n```typescript\ninterface ModernInputProps {\n  label?: string;\n  placeholder?: string;\n  value: string;\n  onChangeText: (text: string) => void;\n  keyboardType?: 'default' | 'numeric' | 'email-address';\n  error?: string;\n  icon?: string;\n  rightIcon?: string;\n  disabled?: boolean;\n}\n```\n\n### Chip\n\nSmall interactive component for selections.\n\n**Variants:**\n- `filled` - Solid background\n- `outlined` - Border only (default)\n- `elevated` - With shadow\n\n**Sizes:**\n- `sm` - 28px height\n- `md` - 32px height (default)\n- `lg` - 40px height\n\n**Props:**\n```typescript\ninterface ChipProps {\n  label: string;\n  selected?: boolean;\n  onPress?: () => void;\n  variant?: 'filled' | 'outlined' | 'elevated';\n  size?: 'sm' | 'md' | 'lg';\n  icon?: string;\n  disabled?: boolean;\n}\n```\n\n---\n\n## 📱 Screen Layouts\n\n### Calculator Screen (V2)\n\n**Structure:**\n1. Header with icon\n2. Madhab selection (Chips)\n3. Estate input (ModernInput)\n4. Heirs selection (Chips grid)\n5. Action buttons\n6. Results display (if calculated)\n\n**Key Features:**\n- Real-time validation\n- Clear error messages\n- Organized heir categories\n- Results in multiple views (table, chart, details)\n\n### Madhab Comparison Screen (V2)\n\n**Structure:**\n1. Header with icon\n2. Estate input\n3. Heirs selection\n4. Comparison button\n5. Results for all 4 Madhabs\n\n**Key Features:**\n- Side-by-side comparison\n- Color-coded Madhabs\n- Detailed heir information\n- Total distribution summary\n\n### Settings Screen (V2)\n\n**Sections:**\n1. Preferences (toggles)\n2. About & Support (links)\n3. App Information\n4. Fiqh Information\n5. Action buttons\n\n**Key Features:**\n- Organized sections\n- Easy navigation\n- Clear descriptions\n- Quick access to support\n\n---\n\n## 🎯 Design Principles\n\n### 1. Clarity\n- Clear labels and descriptions\n- Obvious call-to-action buttons\n- Logical information hierarchy\n\n### 2. Consistency\n- Unified color scheme\n- Consistent spacing\n- Standardized components\n\n### 3. Accessibility\n- Sufficient color contrast\n- Large touch targets (min 48px)\n- Clear focus states\n- Support for screen readers\n\n### 4. Performance\n- Optimized animations\n- Lazy loading for lists\n- Efficient re-renders\n- Cached calculations\n\n### 5. User-Centric\n- Minimal steps to calculate\n- Clear results display\n- Easy error recovery\n- Helpful guidance\n\n---\n\n## 🎨 Usage Examples\n\n### Button Usage\n\n```tsx\nimport { PrimaryButton } from '../components/ui/PrimaryButton';\n\n<PrimaryButton\n  title=\"Calculate\"\n  onPress={handleCalculate}\n  variant=\"filled\"\n  size=\"lg\"\n  icon=\"calculator\"\n  fullWidth\n/>\n```\n\n### Card Usage\n\n```tsx\nimport { ModernCard } from '../components/ui/ModernCard';\n\n<ModernCard variant=\"elevated\" padding={16}>\n  <Text>Card content</Text>\n</ModernCard>\n```\n\n### Input Usage\n\n```tsx\nimport { ModernInput } from '../components/ui/ModernInput';\n\n<ModernInput\n  label=\"Estate Value\"\n  placeholder=\"Enter amount\"\n  value={estateValue}\n  onChangeText={setEstateValue}\n  keyboardType=\"numeric\"\n  icon=\"currency-usd\"\n  error={error}\n/>\n```\n\n### Chip Usage\n\n```tsx\nimport { Chip } from '../components/ui/Chip';\n\n<Chip\n  label=\"Hanafi\"\n  selected={madhab === 'hanafi'}\n  onPress={() => setMadhab('hanafi')}\n  variant=\"outlined\"\n/>\n```\n\n---\n\n## 🌙 Dark Mode Support\n\nAll colors automatically adapt to dark mode through the theme context:\n\n```tsx\nconst { colors } = useTheme();\n\n// Colors automatically adjust based on current theme\nconst backgroundColor = colors.background; // Light or dark\nconst textColor = colors.text; // Light or dark\n```\n\n---\n\n## 📊 Animation Guidelines\n\n### Durations\n- **Shortest**: 150ms - Quick interactions\n- **Shorter**: 200ms - Button feedback\n- **Short**: 250ms - Modal entrance\n- **Standard**: 300ms - Default transitions\n- **Complex**: 375ms - Multi-step animations\n\n### Easing Functions\n- **Linear**: Constant speed\n- **Ease In**: Slow start\n- **Ease Out**: Slow end\n- **Ease In Out**: Smooth both ends\n\n---\n\n## ✅ Best Practices\n\n### Do's\n- ✅ Use theme colors consistently\n- ✅ Follow spacing guidelines\n- ✅ Use semantic colors for states\n- ✅ Provide clear feedback\n- ✅ Test on multiple screen sizes\n\n### Don'ts\n- ❌ Hard-code colors\n- ❌ Mix spacing values\n- ❌ Ignore accessibility\n- ❌ Use too many animations\n- ❌ Forget error states\n\n---\n\n## 📚 Resources\n\n- [Material Design 3](https://m3.material.io/)\n- [React Native Documentation](https://reactnative.dev/)\n- [Expo Documentation](https://docs.expo.dev/)\n\n---\n\n**Last Updated**: May 15, 2026\n**Version**: 1.0\n**Status**: Active\n
