The application supports all four major schools of Islamic law (Madhabs) and provides an intuitive, modern interface for users to perform calculations.\n\n### Key Highlights\n\n✨ **Modern UI/UX**\n- Material Design 3 compliance\n- Responsive layouts\n- Smooth animations\n- Dark mode support\n\n🎓 **Accurate Calculations**\n- All 4 Madhabs supported\n- Precise share calculations\n- Multiple heir types\n- Real-time validation\n\n📊 **Advanced Features**\n- Multiple result views (table, chart, details)\n- PDF export\n- Calculation history\n- Search functionality\n- Statistics tracking\n\n🔒 **Security & Privacy**\n- Local storage only\n- No cloud tracking\n- User data privacy\n- Transparent permissions\n\n---\n\n## ✨ Features\n\n### Core Features\n\n#### 1. **Calculator**\n- Select Islamic school (Madhab)\n- Enter estate value\n- Choose applicable heirs\n- Get instant calculations\n- View results in multiple formats\n\n#### 2. **Madhab Comparison**\n- Compare all 4 schools simultaneously\n- Analyze differences\n- Side-by-side results\n- Color-coded display\n\n#### 3. **History Management**\n- Automatic history saving\n- Search functionality\n- Statistics tracking\n- Export/import capabilities\n- Custom notes\n\n#### 4. **Export & Share**\n- PDF export with professional formatting\n- CSV export for spreadsheets\n- JSON export for integration\n- Share via email, messaging, etc.\n\n#### 5. **Settings & Preferences**\n- Notification control\n- Analytics preferences\n- Theme selection\n- Language options\n- Support access\n\n### Supported Madhabs\n\n1. **Hanafi** (الحنفي) - Hanafi School\n2. **Maliki** (المالكي) - Maliki School\n3. **Shafi'i** (الشافعي) - Shafi'i School\n4. **Hanbali** (الحنبلي) - Hanbali School\n\n### Supported Heirs\n\n**Spouses**\n- Husband\n- Wife\n\n**Children**\n- Son\n- Daughter\n\n**Parents**\n- Father\n- Mother\n\n**Siblings**\n- Full Brother\n- Full Sister\n\n**Grandparents**\n- Paternal Grandfather\n- Paternal Grandmother\n- Maternal Grandmother\n\n---\n\n## 📸 Screenshots\n\n### Calculator Screen\n- Clean, organized interface\n- Madhab selection chips\n- Estate input field\n- Heir selection grid\n- Action buttons\n\n### Results Display\n- Table view with detailed breakdown\n- Chart view with visual distribution\n- Details view with expandable cards\n- Export and share options\n\n### History Screen\n- Recent calculations list\n- Statistics summary\n- Search functionality\n- Expandable details\n- Export/delete actions\n\n### Settings Screen\n- Preferences section\n- About & support links\n- App information\n- Madhab information\n- Action buttons\n\n---\n\n## 🚀 Installation\n\n### Prerequisites\n\n- Node.js 16+ and npm/yarn\n- Expo CLI: `npm install -g expo-cli`\n- React Native development environment\n- iOS Simulator or Android Emulator (or physical device)\n\n### Setup Steps\n\n1. **Clone the repository**\n   ```bash\n   git clone https://github.com/Devlopmenteng/merath_mobile.git\n   cd merath_mobile\n   ```\n\n2. **Install dependencies**\n   ```bash\n   npm install\n   # or\n   yarn install\n   ```\n\n3. **Install Expo dependencies**\n   ```bash\n   expo install\n   ```\n\n4. **Start the development server**\n   ```bash\n   npm start\n   # or\n   expo start\n   ```\n\n5. **Run on device**\n   - **iOS**: Press `i` in the terminal\n   - **Android**: Press `a` in the terminal\n   - **Web**: Press `w` in the terminal\n\n### Build for Production\n\n**iOS**\n```bash\neas build --platform ios\n```\n\n**Android**\n```bash\neas build --platform android\n```\n\n**Web**\n```bash\nnpm run build\n```\n\n---\n\n## 📖 Usage\n\n### Basic Calculation\n\n1. **Open Calculator Screen**\n   - Tap the calculator icon in navigation\n\n2. **Select Madhab**\n   - Choose from Hanafi, Maliki, Shafi'i, or Hanbali\n\n3. **Enter Estate Value**\n   - Input the total estate amount in SAR\n\n4. **Select Heirs**\n   - Choose all applicable heirs from the list\n\n5. **Calculate**\n   - Tap the \"Calculate\" button\n\n6. **View Results**\n   - Switch between Table, Chart, and Details views\n   - Export or share results\n\n### Compare Madhabs\n\n1. **Open Madhab Comparison Screen**\n   - Tap the comparison icon\n\n2. **Enter Estate and Heirs**\n   - Same as basic calculation\n\n3. **Compare**\n   - Tap \"Compare Madhabs\"\n   - View all 4 schools side-by-side\n\n### Access History\n\n1. **Open History Screen**\n   - Tap the history icon\n\n2. **View Calculations**\n   - See recent calculations\n   - View statistics\n\n3. **Search**\n   - Use search bar to find calculations\n\n4. **Export or Delete**\n   - Expand calculation\n   - Choose export or delete\n\n---\n\n## 🏗️ Architecture\n\n### Project Structure\n\n```\nmerath_mobile/\n├── screens/\n│   ├── CalculatorScreenV2.tsx\n│   ├── MadhhabComparisonScreenV2.tsx\n│   ├── HistoryScreenV2.tsx\n│   └── SettingsScreenV2.tsx\n├── components/\n│   ├── ui/\n│   │   ├── PrimaryButton.tsx\n│   │   ├── ModernCard.tsx\n│   │   ├── ModernInput.tsx\n│   │   └── Chip.tsx\n│   ├── ResultsTable.tsx\n│   └── AdvancedResultsDisplay.tsx\n├── lib/\n│   ├── theme/\n│   │   ├── colors.ts\n│   │   ├── spacing.ts\n│   │   ├── index.ts\n│   │   └── useTheme.ts\n│   ├── services/\n│   │   ├── ExportService.ts\n│   │   └── HistoryService.ts\n│   ├── context/\n│   │   ├── MadhabContext.tsx\n│   │   ├── ThemeProvider.tsx\n│   │   └── ResultsContext.tsx\n│   └── hooks/\n│       ├── useCalculator.ts\n│       ├── useResults.ts\n│       └── useTheme.ts\n├── App.tsx\n├── package.json\n└── README.md\n```\n\n### Technology Stack\n\n**Frontend**\n- React Native 0.72+\n- Expo 49+\n- TypeScript\n- React Navigation\n- Reanimated 2\n\n**State Management**\n- React Context API\n- AsyncStorage\n\n**UI/UX**\n- Material Design 3\n- Custom Design System\n- Tailwind CSS (web)\n\n**Services**\n- Export Service (PDF, CSV, JSON)\n- History Service (AsyncStorage)\n- Theme Service (Dark/Light mode)\n\n---\n\n## 🎨 Design System\n\n### Color Palette\n\n**Primary**: `#4CAF50` (Islamic Green)\n**Secondary**: `#2196F3` (Professional Blue)\n**Success**: `#4CAF50`\n**Error**: `#F44336`\n**Warning**: `#FBC02D`\n**Info**: `#03A9F4`\n\n### Typography\n\n- **Display**: 57px -
